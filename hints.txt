CRITICAL: Avoid Undefined (X/Z) Values

1. Use 'assign' statements for ALL outputs - never use procedural blocks (always_comb/always) for outputs
2. Every conditional must assign a value in BOTH branches - use ternary operator: assign output = condition ? value1 : value2;
3. All internal signals must be assigned before being used
4. Use generate loops with assign statements, not procedural blocks
5. Verify: addr_out[55:0] and cs_out[3:0] are assigned using 'assign' statements

Example pattern:
  assign addr_phase_processed[i] = (condition) ? value1 : value2;  // ✅ Always assigns
  NOT: if (condition) value = x; else value = y;  // ❌ May leave undefined

Common mistake: Missing 'assign' keyword or incomplete conditionals that leave outputs undefined.
